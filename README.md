## Coordinate convention

All feature vectors are row vectors:

```text
R_NT : NONE     -> teacher
R_ST : CLEAN-KD -> teacher
R_TS : teacher  -> CLEAN-KD = R_ST.T

N_T = N @ R_NT
S_T = S @ R_ST
T_S = T @ R_ST.T
```

A raw NONE vector is never projected against a teacher vector while the two are expressed in different learned feature coordinates.

### Experiment-4 intervention geometry

For a locked object support region `R_H`, every NONE cell is first mapped N→T. The complete region is then flattened and **one scalar projection coefficient** is computed for that region. Canonical complement ablation/rescue preserves this authoritative flattened-region definition.

### TSG / TSOG geometry

Task-sensitive geometry instead works with **per-cell 256-D directions** at unique spatial CORE9 object-center P4 cells. Multiple objects landing on the same spatial P4 cell contribute one intervention cell.

## Native-loss replay is part of the protocol

See [`docs/NATIVE_LOSS_CONTRACT.md`](docs/NATIVE_LOSS_CONTRACT.md).

In brief:

- **YOLO11s:** model stays frozen/eval; only the Detect container's own `training` flag is set to expose raw outputs; Detect children/BatchNorm stay eval.
- **RT-DETR-L:** model stays eval, lazy criterion is initialized once when necessary, `model.loss(batch)` is called explicitly, and the same prospectively frozen per-view RNG seed is reset before every baseline/intervention loss.

These are scientific replay contracts, not implementation conveniences.

For checkpoint interventions, canonical maps are cast to the frozen feature
`float32` dtype/device before N→T projection and T→S mapping. When a manifest
contains a prospectively frozen `view_index`, rc2 preserves that ordering for
feature-map accumulation and replay instead of re-sorting by filename/source.

## Frozen Gaussian generator

TRAIN/VAL views use:

```text
generator version : consrestore_exp1_training_gaussian_v1
master seed       : 2027
sigma             : {15,25,50}
RNG               : numpy.random.default_rng(per-view SHA-256 seed)
noise             : N(0,sigma)
quantization      : rint -> clip[0,255] -> uint8
PNG               : optimize=False
```

The seed is the unsigned big-endian integer from the first eight SHA-256 bytes of:

```text
{generator_version}|master_seed=2027|split={split}|source={source_stem}|sigma={sigma}
```
