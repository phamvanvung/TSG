# Stable v1.0 closure procedure

rc2 incorporated the first complete author-machine checkpoint execution and the resulting target reconciliation. Stable v1.0 release closure is now complete: the exact successful environment is frozen and the final end-to-end verifier reports `FULL_CHECKPOINT_REPRODUCTION_PASS`.

## 1. Stage bundle-safe author artifacts

On the author machine, using the working machine-specific config:

```bash
python scripts/stage_public_reference_artifacts.py \
  --config configs/paths.json
```

This copies and hash-verifies the small teacher-canonical YOLO maps, frozen YOLO `C_g`, exact Experiment-4 random helper, checkpoint companion source files, historical RT-DETR Step-10 bridge, and YOLO native-loss args. It does **not** copy BDD100K or trained checkpoints.

## 2. Configure third-party/private large assets

For the public-style run:

```bash
cp configs/paths.example.json configs/paths.json
```

Fill only the BDD100K-derived manifests/root and the three YOLO + three RT-DETR checkpoint paths. The bundled small reference artifacts already have relative paths in the template.

## 3. Run source validation

```bash
make check
```

## 4. Execute the checkpoint chains

```bash
python scripts/yolo/run_yolo_reproduction.py \
  --config configs/paths.json \
  --through exp16a \
  --include-random-control
```

```bash
python scripts/rtdetr/run_rtdetr_reproduction.py \
  --config configs/paths.json \
  --through orientation
```

The RT-DETR order is:

```text
preflight
 -> Gaussian VAL detector evaluation
 -> teacher-canonical maps
 -> task-sensitive C_g
 -> Step-12 local utility
 -> Step-14 finite horizon using the local Step-12 cell table
 -> teacher-canonical orientation
```

## 5. Capture the exact successful environment

```bash
python scripts/verify_environment.py \
  --require-cuda \
  --output results/environment_successful_run.json
```

Copy the observed exact values for:

```text
python
numpy
scipy
pandas
torch
torch_cuda
cudnn
gpu
```

into `configs/environment.requirements.json` under `freeze_from_successful_reference_run`.

Run the environment verifier again. It must report:

```text
status            PASS
contract_complete true
```

## 6. Final numerical closure

```bash
python scripts/verify_end_to_end.py \
  --results-root results \
  --environment-report results/environment_successful_run.json
```

Stable v1.0 requires exactly:

```text
FULL_CHECKPOINT_REPRODUCTION_PASS
```

The verifier also checks that Step 14 consumed exactly the Step-12 cell table generated by the same public run.

## 7. Sanitize and freeze the archive

Remove the machine-specific `configs/paths.json`, then run:

```bash
make check
make manifest
```

Confirm the private-path scan is clean, create the final archive, test archive integrity, and record the archive SHA-256 in the release notes.

## Freeze the successful execution environment

After the checkpoint chains and detector evaluation complete on the designated reproduction machine:

```bash
python scripts/verify_environment.py \
  --require-cuda \
  --output results/environment_successful_run.json

python scripts/freeze_environment_from_report.py \
  --report results/environment_successful_run.json \
  --write

python scripts/verify_environment.py \
  --require-cuda \
  --output results/environment_successful_run.json
```

The second environment verification must report both `status: PASS` and
`contract_complete: true` before stable-v1 closure.
