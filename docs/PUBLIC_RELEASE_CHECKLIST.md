# Public stable-v1 release checklist

Stable `v1.0` is ready only when every item below is satisfied.

- [ ] `make check` passes from the release tree.
- [ ] `scripts/stage_public_reference_artifacts.py` has staged the small author-generated replay artifacts and companions.
- [ ] No BDD100K imagery/labels or trained detector checkpoints are included in the archive.
- [ ] YOLO preflight passes all frozen checkpoint/data/helper hashes.
- [ ] YOLO full chain including random control completes.
- [ ] RT-DETR preflight passes all frozen checkpoint/bridge/manifest hashes.
- [ ] RT-DETR Gaussian VAL detector evaluation completes.
- [ ] RT-DETR maps, task geometry, Step-12, Step-14, and orientation complete.
- [ ] Step-14 provenance hash equals the Step-12 cell table generated by the same public run.
- [ ] `scripts/verify_environment.py --require-cuda` captures the successful execution environment.
- [ ] Exact Python, PyTorch, CUDA, cuDNN, GPU, NumPy, SciPy, and pandas values are frozen in `configs/environment.requirements.json`.
- [ ] Re-running the environment verifier reports `PASS` and `contract_complete: true`.
- [ ] `scripts/verify_end_to_end.py` reports `FULL_CHECKPOINT_REPRODUCTION_PASS`.
- [ ] Machine-specific `configs/paths.json` is excluded from both `MANIFEST.txt` and the public archive.
- [ ] No author-machine absolute home path or other private machine path occurs in release source/config/reference files.
- [ ] `make manifest` is run after all release files are final.
- [ ] Archive integrity is tested and archive SHA-256 is recorded in release notes.
- [ ] `CITATION.cff` is updated with the final paper DOI/identifier when available.
- [ ] A repository `LICENSE` has been deliberately selected by the author and is compatible with the bundled project-authored code.

The legacy rc1 target JSON is retained only as an audit record and must not be used as a stable-release gate.
